# fleetops-dispatch-platform

A fictional enterprise logistics application used as a multi-language secret-scanner
test repository. It models vehicle tracking, delivery dispatch, route management,
and proof of delivery.

## Languages
- Ruby — maps integration
- Rust — route gateway
- Kotlin — proof-of-delivery crypto stub
- Swift — dispatch status
- Dart — driver check-in
- Scala — dispatch events

## Credential categories
`API_KEY`, `ACCESS_TOKEN`, `PRIVATE_KEY`, `DATABASE_CREDENTIAL`,
`CLOUD_SECRET`, `ENCRYPTION_KEY`, and `NO_CREDENTIAL`.

`PASSWORD` and `AUTH_TOKEN` are intentionally excluded.

## Safety notice
All credential-like values are synthetic, non-functional placeholders for scanner
testing. Do not replace them with real secrets.
